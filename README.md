# Anime Rush

**Anime Rush** is an anime-inspired game project developed on Roblox, accompanied by a dedicated web platform designed to act as a Wiki and companion website for the game.

The platform will contain information about the game's characters, systems, mechanics, updates, and other content, while also providing features connected to the player's Roblox account.

> 🚧 **Project status: In Development**

## About the Project

Anime Rush is being developed as a project that combines **game development and web development** into a single ecosystem.

The web platform will initially serve as a Wiki containing information about the game. As development progresses, it will evolve into a companion platform connected to the Roblox game.

The long-term goal is to allow players to connect their Roblox account to the website and access features and information related to their in-game account.
